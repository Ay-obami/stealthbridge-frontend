# StealthBridge Frontend

Frontend workspace for StealthBridge Business and StealthBridge Send. Testnet-only architecture phase.

Planned: `apps/business`, `apps/send`, shared UI, wallet signing and versioned API/SDK clients. No real funds, seed storage or server-side ZK witnesses.

Integrates with `stealthbridge-backend`, `stealthbridge-sdk` and `stealthbridge-contracts`.
